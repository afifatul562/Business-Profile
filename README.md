# 🪑 Yakin Perabot - Business Profile Website

Website profil bisnis untuk **Yakin Perabot**, toko mebel tertua di Kota Payakumbuh, Sumatera Barat yang telah berdiri sejak tahun 1975.

## 📋 Tentang Proyek

Website ini merupakan profil bisnis digital untuk Yakin Perabot yang menampilkan informasi tentang perusahaan, produk, dan kontak. Website dibangun menggunakan HTML, CSS, dan JavaScript untuk memberikan pengalaman browsing yang responsif dan modern.

## ✨ Fitur

- 🏠 **Home Page** - Halaman utama dengan banner dan ringkasan informasi
- 📖 **About** - Halaman tentang sejarah dan profil bisnis Yakin Perabot
- 🛋️ **Product** - Halaman produk yang menampilkan kategori produk utama
- 📞 **Contact** - Halaman kontak untuk menghubungi bisnis
- 📱 **Responsive Design** - Tampilan yang menyesuaikan dengan berbagai ukuran layar
- ⚡ **Loading Animation** - Animasi loading saat halaman dimuat
- 🔗 **Social Media Links** - Tautan ke Facebook, Instagram, dan TikTok

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur halaman web
- **CSS3** - Styling dan layout
- **jQuery** - JavaScript library untuk interaktivitas
- **Font Awesome** - Icons untuk UI
- **Google Fonts** (jika digunakan)

## 🚀 Cara Menjalankan

### Opsi 1: Buka Langsung di Browser
1. Download atau clone repository ini
2. Buka file `index.html` langsung di browser Anda

### Opsi 2: Menggunakan Local Server

**Menggunakan Python:**
```bash
python -m http.server 8000
```
Kemudian buka browser dan akses: `http://localhost:8000`

**Menggunakan Node.js (http-server):**
```bash
npx http-server
```
